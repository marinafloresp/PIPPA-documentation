# Q&A about PIPPA

_Q. What sequencing data can I used?_

A. PIPPA has been developed for cell type-sorted paired-end ATAC-seq data. However, it can also be used with bulk ATAC-seq data. The peak curation stage could also be adapted to be used for any sequencing data that is used to call peaks, e.g. CUT&TAG.

_Q. Is it only for brain data?_

A. No! PIPPA is not tissue dependent, so any type of ATAC-seq data can be used.
