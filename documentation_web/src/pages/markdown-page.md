# Welcome to the documentation page for PIPPA!

Pipeline for Integrative Peak calling in Population-scale ATAC-seq (**PIPPA**) provides end-to-end quality control and processing of ATAC-seq datasets and curated of reproducible peak sets. The pipeline can be found at
[PIPPA repository](https://github.com/ejh243/BrainFANS/tree/master/sequencing/ATACSeq).

For a quickstart guide, please consult the
[README](https://github.com/ejh243/BrainFANS/tree/master/sequencing/ATACSeq) on the GitHub page.

Here you will find further information about **PIPPA**, including the stages and steps, how to set up the pipeline, the requirements, pipeline explanations and more. Please start at the 'documentation' navigation bar at the top of this page. 

If you would like to know more about **PIPPA**, visit the 'About' page. If you need help related to the pipeline or have questions, please visit the 'Help' page for further information.
